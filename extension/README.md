# Extension

Coloque aqui todos os arquivos da sua extensão Chrome (MV3):

- `manifest.json`
- `popup.html` / `popup.js` / `popup.css`
- `background.js`
- `content.js` (se houver)
- ícones, etc.

Esta pasta é isolada do código do site. O site fica em `src/` (raiz do repo)
e a extensão fica aqui em `extension/`.
